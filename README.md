# 👑 뽈이 비서실

보람 님 전용 클레이 3D 비서실 웹페이지.

- **오피스 맵** — 클레이 미니어처 사무실 위의 방 핀(대회의실 · 지휘실 · 라운지)을 눌러 방별 안내를 봅니다.
- **작업실** — 체험단·리뷰 / 뽈로그·스레드·릴스 / 핫딜헌터·응모 / 일상·루틴 보드. 할 일 추가·완료 체크·삭제.
- **비서현황** — 오늘 할 일 통계, 함께 있는 비서, 매일 도는 루틴.
- **회의실** — @멘션 버튼과 안건 보드.
- **메모** — 붙여 두는 메모.

데이터는 브라우저 `localStorage`(`bbori-office-v1`)에 저장됩니다.
여러 피클이 실시간으로 같이 쓰려면 `assets/app.js` 맨 위의 `FIREBASE_CONFIG`를 채우면 됩니다(페이지 안의 안내 참고).

## 구조

```
index.html            단일 페이지
assets/style.css      크림·우드 톤 스타일 (라이트/밤 테마)
assets/app.js         상태·렌더·이벤트, Firebase 어댑터 자리
assets/clay-office.jpg  클레이 3D 오피스 이미지 (1402×1122)
```

## 로컬에서 열기

`index.html`을 브라우저로 열면 됩니다. 별도 빌드 없음.
