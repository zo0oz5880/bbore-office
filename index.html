📝 메모

떠오를 때 바로 적어 두세요
📌 메모는 이 브라우저에 저장돼요.
🔌 여러 피클과 실시간으로 같이 쓰기 (Firebase 연결 안내)

지금은 이 브라우저에만 저장돼요. 다른 피클과 같은 목록을 실시간으로 보려면 Firebase Realtime Database를 붙이면 돼요. 페이지는 이미 그 자리를 비워 두었어요 — assets/app.js 맨 위의 FIREBASE_CONFIG만 채우면 자동으로 전환됩니다.

  1. Firebase 콘솔에서 새 프로젝트를 만들고 Realtime Database를 켭니다.
  2. 프로젝트 설정 → 내 앱(웹)에서 firebaseConfig 값을 복사합니다.
  3. assets/app.js의 FIREBASE_CONFIG에 붙여 넣고 저장합니다.
  4. 규칙(Rules)에서 office 경로만 읽고 쓸 수 있게 열어 둡니다.
// assets/app.js 맨 위
const FIREBASE_CONFIG = {
  apiKey: "…",
  authDomain: "…firebaseapp.com",
  databaseURL: "https://….firebaseio.com",
  projectId: "…",
  appId: "…",
};
const FIREBASE_PATH = "bbori-office"; // 방 하나 = 문서 하나
// Realtime Database 규칙 예시 (테스트용, 나중에 잠그기)
{
  "rules": {
    "bbori-office": {
      ".read": true,
      ".write": true
    }
  }
}

연결되면 작업실·회의실·메모가 모두 같은 내용을 보게 되고, 한 피클이 체크하면 다른 피클 화면에도 바로 반영돼요.
