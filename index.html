📝 메모

떠오를 때 바로 적어 두세요
📌 메모는 실시간으로 함께 저장돼요.
🔌 여러 피클과 실시간으로 같이 쓰기 (연결됨 · Firebase bbore-office)

연결됐어요. Firebase Realtime Database bbore-office 프로젝트의 https://bbore-office-default-rtdb.firebaseio.com 아래 bbori-office 경로 하나에 할 일·안건·메모가 모두 들어 있습니다. 한 피클이 체크하면 다른 피클·다른 기기 화면에도 바로 반영되고, 새로고침하거나 브라우저를 닫았다 열어도 그대로 남아 있어요.

  • 프로젝트: bbore-office · Spark 무료 요금제
  • 설정값: assets/app.js 맨 위 FIREBASE_CONFIG (공개 웹 앱 설정 — 비밀값 아님)
  • 규칙: bbori-office 경로만 읽기/쓰기 허용, 그 밖의 경로는 막혀 있습니다.
  • 연결이 잠시 끊기면 이 브라우저에 먼저 저장해 두고, 다시 연결되면 DB로 올립니다. 상태는 화면 맨 아래에 표시돼요.
// Realtime Database 규칙 (현재 적용 중)
{
  "rules": {
    "bbori-office": {
      ".read": true,
      ".write": true
    }
  }
}

목록 전체를 한 문서로 저장하는 방식이라, 두 기기에서 동시에 고치면 나중에 저장한 쪽이 남습니다. 혼자 쓰는 목록이라 보통은 문제되지 않아요.
